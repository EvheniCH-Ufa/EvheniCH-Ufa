# Telegram Bot Prototype

## Описание
Прототип Telegram-бота на Python, отправляющий сообщения в ТГ-канал о новых CVE уязвимостях и получающий запрос на предоставление информации о конкретной CVE уязвимости

## Функциональность
- /start - приветственное сообщение
- /get_cve ХХХ - запрос информации о CVE уязвимости
- /end - выключает бота
